# SRH Fan Hub - Official Fan Experience

Welcome to **SRH Fan Hub**, 
a fan-made web portal dedicated to **Sunrisers Hyderabad (SRH)** 
-the fiery IPL team! This project is designed to provide fans with team info, schedules, polls, news, and live Twitter updates

---

## 🔹 Features

- **Home Page & Hero Section:** Welcome message and fan hub introduction.
- **Why SRH?** Highlights team legacy, spirit, and iconic captains.
- **Match Schedule Preview:** Quick view of upcoming matches with a link to the full schedule.
- **Star Players:** Page linking to player profiles and stats.
- **Latest News:** Section to display SRH news (currently placeholder for updates).
- **Fan Poll:** Vote for your favorite SRH player with instant feedback.
- **Live Twitter Feed:** Embedded timeline showing live tweets from [@SunRisers](https://twitter.com/SunRisers).
- **Responsive Design:** Works on mobile, tablet, and desktop.
- **Social Media Links:** Quick access to Twitter, Instagram, and Facebook.



## 🔹 Technologies Used

- HTML5, CSS3  
- JavaScript (Vanilla JS for polls)  
- Google Fonts (`Orbitron`)  
- Font Awesome icons  
- Twitter Embedded Timeline API
